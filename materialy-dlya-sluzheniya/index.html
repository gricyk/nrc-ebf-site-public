Служителям

Материалы для служения

Сайты и программы Библий в помощь: Самостоятельное изучение Библии, Библия онлайн, Библейский сервер, Служение III Тысячелетие

Более 130 часов наглядных материалов на 17 языках. Перечень русскоязычных материалов здесь: http://r.thirdmill.org/seminary

  • Книги по ученичеству (скачать) рус. - 7 книг по ученичеству. Бонхоуфер - Цена ученичества. Билл Хулл - обучающий пастор. Коулман - Генеральный план евангелизма. Фостер Ричард - Прославление дисциплины. Гордон Макдональд - Как упорядочить свой внутренний мир. Фома Кемпийский - О подражании Христу. Тозер - Стремление к Богу.
  • SEAN (скачать) рус. - серия занятий для малых групп. Представлены все курсы от ведения человека к вере, подготовки к крещению, к взращиванию верующих в вере. Подготовка проповедников
  • Elements (скачать) рус. - серия из 10 уроков для новообращенной молодежи. (есть и на других языках)
  • К Нему по одному (скачать) рус. - серия из 24 уроков для подготовки к крещению
  • Уроки по ученичеству (скачать) рус. - серия из 10 уроков для новообращенных подростков, но можно использовать для всех и постарше
  • 10 заповедей (скачать) рус. - серия занятий по 10 заповедям
  • Альфа курсы (скачать) рус. - знаменитые альфа курсы предназначены для неверующих
  • Знакомство с Библией (скачать) укр. - серия уроков на ознакомление со Священным Писанием на украинском языке
  • Благочестивая жизнь христианина (скачать) укр. - серия занятий для возрастания в благочестии на украинском языке
  • Брак без сожаления (скачать) рус. - 15 уроков по созданию брака и жизни в браке
  • Духовный рост (скачать) рус. - 8 тем, материал разработан на основании материалов Б. Вилкинсона
  • Завет (скачать) рус. - программа из 11 занятий из курса “От наставления к наставлению”
  • Имена Бога (скачать) рус. - 42 дня обучения именам Бога разработано Кей Артур
  • Личная святость (скачать) рус. - 4 урока по личной святости христианина
  • Супружеская жизнь (скачать) укр. - 14 занятий по теме супружеской жизни на украинском языке
  • Духовные дары (скачать) рус. - тесты по духовным дарам
  • Созидание церкви (скачать) рус. - уроки по созиданию церкви Христовой
  • Воскресная школа для детей (скачать) рус. - годичная программа для детского служения. Больше материала по служению детям, подросткам и молодежи тут http://lager.ucoz.ru/load
  • Библия за год (скачать) рус. - 4 разных плана чтения Библии за год
